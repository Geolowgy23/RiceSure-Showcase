# RiceSure — Agritech Grain Quality Intelligence

RiceSure is an agritech computer vision framework developed at the Holy Cross of Davao College[cite: 1]. It utilizes Convolutional Neural Network (CNN) image segmentation to detect rice grain cultivar adulteration and verify variety purity kernel-by-kernel directly on mobile flatbeds without laboratory assays[cite: 1].

---

## Key Features

* **Calibrated Flatbed Ingestion**: Captures high-contrast sample tray imagery directly using mobile camera sensors[cite: 1].
* **CNN Morphological Segmentation**: Automatically isolates individual grains and tags contaminant or filler kernels in mixed cultivar runs[cite: 1].
* **On-Device Batch Purity Output**: Calculates instantaneous purity percentage ratings to support fair market pricing and protect certified harvest stocks[cite: 1].
